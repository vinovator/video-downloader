    Download

    This page writes the yt-dlp command for you. Paste it into Terminal and the file is saved on your computer. To download straight from this page instead, start the helper.
    Set up the helper, once
    1. Install yt-dlp and ffmpeg. On a Mac: brew install yt-dlp ffmpeg On Windows: winget install yt-dlp.yt-dlp Gyan.FFmpeg DenoLand.Deno On Linux: pipx install "yt-dlp[default]", then ffmpeg and deno from your package manager.
    2. Download the helper, one small file that needs Node 18 or newer.
    3. Run node ~/Downloads/video-downloader-helper.mjs. It opens this page from your own computer, with real formats, sizes and a Download button.
